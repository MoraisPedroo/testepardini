PASTA DE INSTALADORES
=====================

Nomes de arquivo esperados pelos botoes do index.html:

  DPPrinterSetup.exe                  -> Download DPPrinter (botao principal)
  zebra-browser-print.exe             -> Download Browser Print
  GTI Printer Proxy 3 Pardini.exe     -> Download WCPP

Se trocar algum nome, ajuste o href correspondente no index.html
(espacos no nome viram %20 na URL).

ATENCAO - LIMITE DO GITHUB
--------------------------
Estes .exe NAO sao versionados no Git (ver .gitignore), e o
"GTI Printer Proxy 3 Pardini.exe" tem ~130 MB: acima do limite de
100 MB por arquivo do GitHub, ele nao pode ser commitado nem com o
.gitignore ajustado.

Enquanto os arquivos nao estiverem hospedados em algum lugar acessivel,
os tres botoes de download vao dar 404 no site publicado. Opcoes:
  - hospedar os instaladores na rede interna e apontar os href para la;
  - servir o portal inteiro pelo servidor interno, com esta pasta junto.
