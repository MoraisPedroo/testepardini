SDK DO ZEBRA BROWSER PRINT (opcional)
=====================================

O portal funciona sem estes arquivos: nesse caso ele conversa direto com a
API HTTP local do servico Browser Print (127.0.0.1:9100).

Para usar o SDK oficial (recomendado), copie para esta pasta os arquivos que
acompanham a instalacao do Zebra Browser Print:

  BrowserPrint-3.1.250.min.js
  BrowserPrint-Zebra-1.1.250.min.js

Se a sua versao tiver outro numero, ajuste as tags <script src="js/..."> no
final do index.php e rode build.ps1 para regerar a versao estatica.
