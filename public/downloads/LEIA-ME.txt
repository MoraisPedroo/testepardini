PASTA DE INSTALADORES
=====================

Coloque aqui os executaveis, usando EXATAMENTE estes nomes de arquivo
(sao os nomes referenciados pelos botoes de download do portal):

  ZebraBrowserPrintSetup.exe   -> Zebra Browser Print (ZBP)
  WebClientPrintSetup.exe      -> WebClientPrint / WCPP (GTI)
  DPPrinterSetup.exe           -> DPPrinter (middleware Node.js)

Se preferir outros nomes, altere os atributos href= da secao
"Downloads dos programas" no arquivo index.php e rode build.ps1
para regerar a versao estatica.

Observacao: os instaladores nao sao versionados no Git (ver .gitignore).
Para a versao publicada na Vercel, os arquivos precisam estar em
public/downloads/ -- o build.ps1 faz essa copia automaticamente.
